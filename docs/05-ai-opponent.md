# PRD 05 — 컴퓨터 상대

## 1. 목표

- 수지 50부터 프로까지 단계를 골라 대전할 수 있다.
- 각 단계가 실제 그 수지의 사람처럼 친다. 낮은 수지는 "일부러 못 치는 기계"가 아니라 "아는 만큼만 보고 실력만큼 실수하는 사람"이어야 한다.
- 프로 단계는 전 레퍼토리를 구사하되 사람이 낼 수 있는 정밀도를 넘지 않는다.

## 2. 단계

### 2.1 4구

50, 80, 100, 120, 150, 200, 250, 300, 400, 500, 700, 1000, 프로 (13단계)

### 2.2 3쿠션

4구와 수지 체계가 다르므로 별도 단계표를 둔다. 초안: 입문, 15점, 18점, 20점, 23점, 25점, 28점, 30점, 35점, 40점, 프로 [초기값, 동호인 검토 필요].

## 3. 구조

```
현재 배치
  → ① 샷 후보 생성
  → ② 물리 코어로 시뮬레이션
  → ③ 평가 (득점 확률, 다음 배치, 수비)
  → ④ 수지에 맞는 선택
  → ⑤ 실행 오차 적용
  → 샷 실행
```

AI는 사람과 **같은 물리 코어, 같은 ShotInput**을 쓴다. AI만의 특수 물리는 없다.

### ① 샷 후보 생성
- 조준 방향, 당점, 속도, 고각의 조합을 탐색한다.
- 무작위 전수 탐색이 아니라 당구 지식 기반으로 후보를 만든다: 목적구별 두께 범위, 유형별 템플릿(뒤돌리기, 앞돌리기, 옆돌리기, 빗겨치기, 더블쿠션, 대회전 등).
- 수지별로 사용 가능한 템플릿과 당점·속도 범위를 제한한다(아래 표).

### ② 시뮬레이션
- 각 후보를 물리 코어로 실행. 빠른 쿠션 모델로 대량 탐색하고, 상위 후보만 정밀 모델로 재확인.
- Web Worker에서 실행해 화면이 멈추지 않게 한다.

### ③ 평가
- **성공 확률**: 후보 주변에 해당 수지의 오차를 넣어 여러 번 시뮬레이션하고 성공 비율을 구한다. "맞긴 하지만 조금만 틀려도 빠지는 샷"을 걸러낸다.
- **다음 배치 가치**: 성공 후 공들이 다음에 치기 좋은 위치에 모이는지.
- **수비 가치**: 실패했을 때 상대에게 어려운 배치를 남기는지.

### ④ 선택
- 수지별 가중치로 종합 점수를 계산해 고른다.
- 낮은 수지는 성공 확률만 보거나, 그마저도 부정확하게 판단한다(판단 오류).

### ⑤ 실행 오차
- 선택한 샷에 수지별 오차를 넣는다.
- 오차는 사람의 실수 패턴을 따른다.
  - 속도가 빠를수록 조준·당점 오차 증가
  - 당점이 중심에서 멀수록 오차 증가 (미스큐 포함)
  - 고각이 클수록 오차 증가
  - 큐가 쿠션에 붙은 불편한 자세일수록 오차 증가

## 4. 수지별 특성 [초기값]

| 요소 | 50~100 | 120~200 | 250~400 | 500~1000 | 프로 |
|---|---|---|---|---|---|
| 조준 오차 (표준편차) | 2.0~1.2° | 1.0~0.7° | 0.6~0.4° | 0.3~0.15° | 0.1° |
| 속도 오차 | ±25% | ±18% | ±12% | ±7% | ±4% |
| 당점 오차 (반지름 대비) | 0.15R | 0.10R | 0.07R | 0.04R | 0.02R |
| 회전 사용 | 거의 중심 | 상하 위주 | 좌우 회전 사용 | 자유 | 자유 |
| 구사 유형 | 직접 맞히기 | 1쿠션 활용 | 기본 돌리기 | 전 유형 | 전 유형 + 마세 |
| 다음 공 고려 | 없음 | 없음 | 일부 | 모아치기 | 모아치기 + 수비 |
| 판단 오류 | 잦음 | 가끔 | 드묾 | 거의 없음 | 없음 |
| 생각 시간 연출 | 길고 불규칙 | 보통 | 보통 | 빠름 | 빠르고 일정 |

모든 수치는 출발점이며 아래 보정 절차로 확정한다.

## 5. 보정

1. 각 단계의 **목표 에버리지**를 정한다. 수지별 실제 에버리지 자료는 사전 조사에서 확보하지 못했으므로 [미확인], 동호인 자료와 테스터 의견으로 초기 목표를 잡는다.
2. AI끼리, 또는 혼자 치는 자동 대국을 단계별로 수천 이닝 돌린다.
3. 측정된 에버리지·하이런 분포가 목표와 맞을 때까지 오차 값을 조정한다.
4. 동호인 테스터가 자기 수지의 AI와 대전해 체감을 확인한다("이건 150 같지 않다").
5. 테이블 조건을 바꿔도 단계 순서가 유지되는지 확인한다.

보정 도구(자동 대국 실행기, 결과 집계)는 개발 초기에 함께 만든다. 물리 회귀 테스트에도 재사용한다.

## 6. 사람다움

- 샷 전에 조준을 조금씩 움직이는 연출, 수지에 맞는 생각 시간.
- 같은 배치에서 항상 같은 샷을 치지 않도록 후보 선택에 약간의 변화.
- 스트로크 입력도 사람과 같은 형태의 궤적을 생성해 리플레이에서 구분되지 않게 한다.
- 고수 단계라도 가끔 실수한다. 실수는 무작위가 아니라 어려운 샷에서 더 자주 난다.

## 7. 부가 기능

- **훈수 모드** (연습): 현재 배치에서 AI가 추천하는 샷 3개를 성공 확률과 함께 표시.
- **수지 추천**: 사용자의 최근 기록으로 맞는 AI 단계를 제안.
- **핸디 대전**: 사람과 AI의 목표 점수를 수지에 따라 다르게.

## 8. 요구사항 요약

- [ ] 단계 선택 UI에서 4구 13단계, 3쿠션 단계를 고를 수 있을 것
- [ ] AI가 사람과 동일한 ShotInput 형식으로 샷을 낼 것
- [ ] AI 계산 중 화면이 멈추지 않을 것 (목표: 샷당 3초 이내 [초기값])
- [ ] 자동 대국으로 단계별 에버리지를 측정하는 도구가 있을 것
- [ ] 단계 간 에버리지가 단조 증가할 것

## 9. 미결 사항

- 수지별 목표 에버리지 값
- 3쿠션 단계표 확정
- 모바일 기기에서의 탐색 시간 (후보 수 축소 또는 서버 계산)
