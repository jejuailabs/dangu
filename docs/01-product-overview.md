# PRD 01 — 제품 개요

## 1. 비전

"당구장에서 치는 것과 같은 결과가 나오는 게임." 실제 당구를 치는 사람이 연습과 복기에 쓸 수 있을 만큼 정확하고, 처음 하는 사람도 링크 하나로 바로 칠 수 있을 만큼 가볍다.

## 2. 타깃 사용자

| 사용자 | 특징 | 원하는 것 |
|---|---|---|
| 당구 동호인 (4구 100~500, 3쿠션 입문~중급) | 실제 당구장을 다님 | 시스템·두께 연습, 배치 복기, 수지에 맞는 상대 |
| 상급자·선수 지망 | 물리에 민감 | 회전·쿠션 반응의 정확성, 정밀 분석 |
| 캐주얼 사용자 | 가끔 즐김 | 쉬운 진입, 친구와 대전, 보조선 |
| 과거 온라인 당구게임 사용자 | 캐롬3D 등 경험 | 4구·3쿠션 온라인 대전의 복귀 |

1차 타깃은 당구 동호인이다. 이들이 "이건 진짜 같다"고 인정해야 나머지가 따라온다.

## 3. 벤치마킹

| 게임 | 강점 | 약점 | 가져올 것 |
|---|---|---|---|
| Virtual Pool 4 [확인] | 물리·조작 평가 최고. 큐 각도, 스쿼트, 스워브 구현. 천·레일 속도, 포켓 조절 | 낡은 UI·그래픽(4:3 메뉴), 무료판·유료판 혼란 | 물리 깊이, 테이블 조건 설정 |
| ShootersPool [확인] | 포켓·스누커·캐롬 지원, 사실적 물리와 그래픽 | 니치, 설치형 | 캐롬 시뮬레이션 방향 |
| Pool Nation [확인] | 연출, Steam 긍정 89% | 물리 독립 검증 없음 | 화면 완성도 |
| 8 Ball Pool [확인] | 압도적 대중성, 쉬운 조작, 빠른 매칭 | 핵 방치, 과금 큐, 물리 불신 | 진입 장벽 낮추기 (반면교사: 과금 구조) |
| VR (MiRacle Pool, Backspin) [확인] | 실제 큐 스트로크 감각 | 장비 필요 | 스트로크 중심 입력 철학 |
| pooltool, tailuge/billiards, CaromSim [확인] | 논문 기반 오픈소스 | 게임 완성도 낮음, 상수 튜닝 미완 | 물리 모델 참고 구현 |
| 캐롬3D 등 국내 게임 [미확인] | 4구·3구 온라인 대전 원조 | 현재 서비스 상태 미확인 | 수지 문화, 한국식 규칙 |
| 당구장 스코어보드 (큐스코, 빌리보드) [확인] | 경기 기록, 영상, 앱 연동 | 영상 기반이라 물리 데이터 없음 | 기록·리플레이 UX |

## 4. 페인포인트 → 니즈 → 대응

| 페인포인트 | 니즈 | 대응 | 관련 PRD |
|---|---|---|---|
| 물리를 못 믿겠다 | 납득되는 결과 | 논문 모델, 계수 공개, 샷 수치 표시 | 02, 08 |
| 파워 게이지는 손맛이 없다 | 스트로크 감각 | 스트로크 궤적 입력 | 03 |
| 핵과 과금 큐 | 공정한 대전 | 서버 재검증, 능력치 비판매 | 06 |
| 낡은 UI, 설치 부담 | 가볍고 현대적인 화면 | 웹, 설치 없음 | 07, 09 |
| 캐롬 시뮬레이터 부재 | 3쿠션·4구 연습 | 캐롬 우선 개발 | 04 |
| 실력이 늘지 않는다 | 학습 도구 | 리플레이, 약점 진단, 배치 저장 | 08 |
| 맞는 상대가 없다 | 수준별 상대 | 수지별 AI, 수지 매칭 | 05, 06 |

## 5. 차별점

1. **캐롬 중심의 논문 기반 물리** — 쿠션에서의 회전 반응이 핵심 경쟁력.
2. **타법이 실제로 다르게 작동** — 스트로크 입력이 임팩트 물리로 직결.
3. **데이터 기반 복기** — 영상이 아닌 물리 데이터 리플레이, 궤적과 회전 오버레이.
4. **수지 체계 그대로** — 한국 동호인에게 익숙한 수지로 AI와 매칭을 표현.
5. **링크 하나로 실행** — 설치·가입 없이 시작.

## 6. 범위

**포함 (1차)**
- 3쿠션, 4구, 연습 모드
- 스트로크 입력, 큐 고각, 테이블 조건 설정
- 로컬·온라인 대전, 컴퓨터 상대
- 스코어보드, 리플레이, 기본 통계

**이후**
- 포켓볼(8볼, 9볼), 샷 유형 분석, 약점 진단, 대회 기능

**제외**
- 능력치가 붙은 유료 큐, 확률형 아이템
- VR, 전용 하드웨어 (입력 구조만 확장 가능하게 설계)

## 7. 성공 지표

| 구분 | 지표 | 목표 [초기값] |
|---|---|---|
| 물리 신뢰 | 검증 테스트 통과율 | 100% |
| 물리 신뢰 | 동호인 테스터의 "실제와 비슷하다" 응답 | 80% 이상 |
| 성능 | 일반 노트북에서 프레임 | 60fps |
| 성능 | 첫 화면 로딩 | 5초 이내 |
| 사용성 | 첫 샷까지 걸리는 시간 | 1분 이내 |
| AI | 수지별 AI의 실측 에버리지와 목표값 오차 | ±10% 이내 |
| 공정성 | 서버 검증 불일치 샷이 결과에 반영된 건수 | 0 |

## 8. 미결 사항

- 서비스 이름
- 수익 모델 (광고, 꾸미기 아이템, 프리미엄 분석 등). 능력치 비판매 원칙만 확정.
- 국내 기존 게임의 현황 재조사
