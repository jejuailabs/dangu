# PRD 07 — 그래픽과 연출

## 1. 목표

- 물리가 **눈으로 읽히게** 한다. 공의 회전, 휨, 쿠션 반응이 화면에서 구분되어야 한다.
- 실제 당구장 같은 사실적인 재질과 조명.
- 일반 노트북 브라우저에서 60fps, 모바일에서 30fps 이상.

## 2. 접근 방식

당구는 형상이 단순하다(구, 테이블, 큐). 사실감은 모델링보다 재질과 조명에서 나온다. 따라서 손으로 그리는 아트 없이 다음 조합으로 구현한다.

| 요소 | 방법 |
|---|---|
| 테이블, 쿠션, 큐 | 실제 규격 치수로 Blender 스크립트 생성 → glTF 내보내기 |
| 공 | 구 + 코드로 생성한 텍스처 (점, 줄무늬, 숫자) |
| 나무, 천, 가죽 재질 | 무료 PBR 라이브러리 (Poly Haven 등 CC0) |
| 조명·반사 | HDRI 환경맵 + 테이블 상부 조명 |
| 배경 공간 | 1차는 HDRI와 어두운 배경, 이후 간단한 당구장 실내 |
| UI | HTML/CSS 오버레이 |

제약: 고유 캐릭터, 로고, 일러스트는 이 방식으로 만들지 않는다. 필요하면 외부 제작물을 받는다.

## 3. 렌더링 기술

- **Three.js (WebGL2)**. WebGPU는 지원 브라우저에서 선택 적용 검토.
- 물리 기반 재질(PBR). 공은 높은 광택과 선명한 환경 반사.
- 그림자: 테이블 상부 조명 기준의 부드러운 그림자. 공 아래 접지 그림자는 필수(공이 떠 보이지 않게).
- 천: 미세한 섬유 질감의 노멀맵, 낮은 광택.
- 후처리: 톤 매핑, 약한 앰비언트 오클루전. 과한 블룸·피사계 심도는 쓰지 않는다(가독성 우선).
- 품질 단계: 낮음 / 보통 / 높음. 기기 성능을 감지해 자동 선택, 수동 변경 가능.

## 4. 회전 가독성 (최우선)

| 기능 | 내용 |
|---|---|
| 연습구 무늬 | 수구에 점·줄무늬가 있는 공을 기본 제공. 회전 방향과 속도가 보인다 |
| 정확한 회전 표현 | 물리 코어의 3축 회전을 그대로 공의 자세에 적용. 근사 애니메이션 금지 |
| 높은 재생률 보간 | 물리 결과는 운동식이므로 화면 주사율에 맞춰 임의 시각을 계산 (144Hz 대응) |
| 슬로모션 | 임팩트와 충돌 순간을 느리게. 리플레이에서 배속 조절 |
| 궤적선 | 공이 지나간 경로를 선으로 남기기 (옵션) |
| 회전 표시 | 회전축 화살표, 회전량 게이지 (연습·리플레이) |
| 미끄럼 표시 | 미끄럼 구간과 구름 구간을 궤적 색으로 구분 (연습·리플레이) |

빠른 회전에서 무늬가 뭉개지는 현상(주사율 한계)은 모션 블러 텍스처 또는 회전 표시로 보완한다.

## 5. 카메라

| 시점 | 용도 |
|---|---|
| 조준 시점 | 큐 뒤 낮은 위치, 실제 엎드린 자세의 시선 |
| 탑뷰 | 배치 파악, 시스템 계산, 마세 입력 |
| 자유 시점 | 드래그로 회전, 휠로 확대 |
| 추적 시점 | 샷 후 수구를 따라감 |
| 중계 시점 | 관전·리플레이용 고정 구도 |

- 시점 전환은 부드럽게, 단축키와 버튼 제공.
- 탑뷰는 원근 왜곡이 없는 직교 투영.
- 샷 후 자동 시점(탑뷰 전환 또는 추적)은 설정으로 선택.

## 6. 큐와 스트로크 표현

- 큐는 사용자의 포인터 움직임을 지연 없이 따라간다. 입력 지연은 손맛을 망친다.
- 당점과 고각이 큐의 실제 위치·각도로 보인다.
- 큐가 다른 공이나 쿠션과 겹치는 경우 시각적으로 표시(실제로 칠 수 없는 자세).
- 손(브리지) 표현은 1차에서 생략.

## 7. UI 원칙

- 경기 화면은 테이블이 주인공이다. UI는 가장자리에 최소한으로.
- 스코어보드는 실제 당구장 디지털 점수판과 비슷한 구성(PRD 08).
- 당점 선택기, 고각 표시, 스트로크 피드백은 반투명 패널.
- 한국어 기본, 다국어 구조 준비.
- 색각 이상 대응: 공 구분을 색만이 아닌 무늬로도.

## 8. 사운드

물리 이벤트에서 직접 구동한다. 소리도 물리 정보의 일부다.

| 이벤트 | 소리 | 변화 요인 |
|---|---|---|
| 큐 타격 | 팁이 공을 치는 소리 | 속도, 당점(중심에서 멀수록 둔탁), 미스큐는 별도 소리 |
| 공-공 충돌 | 딱 소리 | 충돌 속도에 따라 크기와 음색 |
| 공-쿠션 | 둔탁한 소리 | 속도 |
| 구름 | 낮은 구름 소리 | 속도 (옵션) |
| 점프 착지 | 바닥 소리 | 낙하 속도 |

- 음원은 무료 라이선스 효과음 또는 직접 녹음. 합성으로 시작해 교체 가능하게.
- 배경음은 당구장 분위기음, 기본 꺼짐 또는 낮게.

## 9. 성능 목표 [초기값]

| 항목 | 목표 |
|---|---|
| 프레임 | 일반 노트북 60fps, 모바일 30fps 이상 |
| 첫 로딩 | 5초 이내 (압축 텍스처, 지연 로딩) |
| 초기 다운로드 | 10MB 이하 |
| 입력 지연 | 포인터 → 큐 반영 1프레임 이내 |

## 10. 요구사항 요약

- [ ] 공의 회전이 물리 값과 정확히 일치하게 표시될 것
- [ ] 무늬 있는 연습구를 제공할 것
- [ ] 다섯 가지 카메라 시점과 전환을 제공할 것
- [ ] 품질 단계 자동·수동 선택을 제공할 것
- [ ] 소리가 물리 이벤트의 세기에 따라 변할 것
- [ ] 리플레이에서 슬로모션과 궤적·회전 오버레이를 지원할 것

## 11. 미결 사항

- 시각적 분위기 (사실적 당구장 / 깔끔한 스튜디오풍) — 사용자 확인 필요
- 배경 공간의 범위
- 효과음 출처
