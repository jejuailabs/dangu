# PRD 04 — 종목과 규칙

## 1. 종목 우선순위

| 단계 | 종목 |
|---|---|
| 1차 | 3쿠션, 4구, 연습 모드 |
| 2차 | 포켓볼 (8볼, 9볼) |
| 검토 | 1쿠션, 프리(3구), 스누커 |

규칙 로직은 물리 코어와 분리된 별도 모듈로 만든다. 물리 코어가 내놓는 이벤트 목록(누가 무엇에 언제 닿았는지)만 보고 득점과 파울을 판정한다.

## 2. 3쿠션

### 2.1 기본 규칙
- 공 3개: 수구 2개(흰 공, 노란 공), 적구 1개(빨간 공). 각자 자기 수구만 친다.
- 득점: 수구가 두 번째 목적구에 닿기 전에 쿠션에 3번 이상 닿고, 두 목적구를 모두 맞히면 1점.
- 득점하면 계속 치고, 실패하면 상대 차례(이닝 종료).
- 목표 점수에 먼저 도달하면 승리. 후구(동일 이닝 기회) 적용 여부는 설정.

### 2.2 파울
- 상대 수구를 침, 공이 테이블 밖으로 나감, 공이 멈추기 전에 침, 제한 시간 초과 등.
- 파울은 이닝 종료. 장외 시 공은 지정 위치에 재배치.

### 2.3 부가 규칙 (설정)
- 초구 배치와 초구 규칙
- 샷 제한 시간 (기본 40초 [초기값]), 타임아웃 횟수
- 프로즌(공이 붙은 경우) 처리
- 목표 점수와 핸디(수지에 따른 목표 점수 차등)

### 2.4 판정에 필요한 이벤트
- 수구의 쿠션 접촉 횟수와 순서, 목적구 접촉 순서. 같은 쿠션 연속 접촉도 각각 센다.

## 3. 4구 (한국식)

### 3.1 기본 규칙
- 공 4개: 수구 2개(흰 공, 노란 공), 빨간 공 2개.
- 득점: 자기 수구로 빨간 공 2개를 모두 맞히면 1점(표시 점수 10점).
- 파울: 상대 수구를 맞히거나, 아무 공도 못 맞히면 감점 후 이닝 종료.
- 목표 점수는 수지에 따른다. 예: 수지 300은 30개.

### 3.2 마무리 규칙 (설정)
- 목표 점수 도달 후 3쿠션(또는 지정 쿠션)으로 마무리해야 승리하는 한국식 관행을 옵션으로 둔다.
- 마무리 쿠션 수, 마무리 실패 시 처리는 방 설정으로 조절.

### 3.3 하우스 룰 옵션
- 파울 감점 크기, 초구 규칙, 붙은 공 처리. 지역·당구장마다 다르므로 프리셋("표준", "동네 규칙")으로 제공. 세부 내용은 [지식] 기반이므로 동호인 검토 필요.

## 4. 포켓볼 (2차)

- 8볼, 9볼. 세계 표준 규칙 기준.
- 물리 추가 요소: 포켓 형상과 낙하 판정, 브레이크의 다중 충돌, 점프 큐.
- 규칙 추가 요소: 콜샷, 프리볼, 푸시아웃, 3연속 파울.

## 5. 연습 모드

| 기능 | 내용 |
|---|---|
| 자유 배치 | 공을 드래그로 놓고, 좌표로 정밀 지정 |
| 되돌리기 | 방금 샷 이전 배치로 즉시 복귀, 무제한 반복 |
| 배치 저장·불러오기 | 이름을 붙여 저장, 링크로 공유 |
| 기본 배치 모음 | 뒤돌리기, 앞돌리기, 빗겨치기, 옆돌리기, 더블쿠션 등 유형별 과제 |
| 시스템 연습 | 다이아몬드 번호 표시, 파이브앤하프 등 계산값과 실제 결과 비교 |
| 전체 예측선 | 현재 설정대로 치면 나올 경로 표시 |
| 수치 입력 | 같은 샷을 수치로 재현 |
| 물리 관찰 | 슬로모션, 회전축 표시, 속도·회전 그래프 |
| 리플레이에서 불러오기 | 지난 경기의 임의 시점 배치로 이동 (PRD 08) |

## 6. 테이블과 장비 설정

### 6.1 테이블 프로파일

| 종류 | 경기면 크기 | 비고 |
|---|---|---|
| 대대 (국제식 캐롬) | 2844 × 1422mm | 3쿠션 표준 [지식] |
| 중대 | 2540 × 1270mm | 한국 4구·동호인 3쿠션 [지식, 재검증] |
| 포켓 9피트 | 2540 × 1270mm | 2차 [지식] |

### 6.2 조건 프리셋
- 천: 새 천(빠름), 보통, 오래된 천(느림)
- 쿠션: 탄성 강함, 보통, 죽은 쿠션
- 환경: 건조, 습함, 히팅 켜짐
- 공: 새 공(미끄러움), 사용한 공
- 기울기: 수평(기본), 임의 방향·각도 설정 (테이블 기울기 실험용)

각 프리셋은 물리 계수 묶음이다(PRD 02의 테이블 프로파일). 사용자 정의 값도 허용.

### 6.3 큐
- 무게, 팁 경도, 스쿼트 특성(저스쿼트 샤프트)의 조합.
- 성능 우열이 아닌 특성 차이로 설계. 유료 판매 대상 아님.
- 대전에서는 방 설정으로 통일하거나 자유 선택.

## 7. 경기 흐름 공통

1. 선공 결정 (뱅킹: 실제로 쳐서 가까운 쪽이 선공, 또는 무작위)
2. 초구
3. 이닝 반복 (샷 → 물리 결과 → 판정 → 계속 또는 교대)
4. 종료 조건 충족
5. 결과 화면 (기록지, 통계, 리플레이 진입)

## 8. 요구사항 요약

- [ ] 규칙 판정은 물리 이벤트 목록만으로 결정될 것 (서버 재검증 가능)
- [ ] 3쿠션·4구의 득점·파울을 자동 판정할 것
- [ ] 하우스 룰을 방 설정으로 조절할 수 있을 것
- [ ] 연습 모드에서 배치 저장·되돌리기·예측선을 제공할 것
- [ ] 테이블 조건이 물리 계수에 직접 연결될 것

## 9. 미결 사항

- 한국식 4구 세부 규칙의 표준안 (동호인 검토 필요)
- 중대·4구 공의 정확한 규격
- 3쿠션 수지 단계표 (PRD 05와 연동)
