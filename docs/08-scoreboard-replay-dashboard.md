# PRD 08 — 스코어보드, 다시 돌려보기, 대시보드

## 1. 목표

최신 당구장 디지털 스코어보드(큐스코, 빌리보드 등)가 제공하는 기록·영상 기능을 모두 갖추고, 게임만이 가능한 물리 데이터 분석을 더한다.

## 2. 기준이 되는 실제 시스템

| 시스템 | 확인된 기능 |
|---|---|
| 큐스코 [확인] | UMB·대한당구연맹 공식 스코어보드. 앱(큐니)에서 경기 기록 집계, 경기 영상 시청, 클럽 경기 실시간 시청 |
| 빌리보드 [확인] | 국내 디지털 점수판 점유율 1위로 소개. PBA 공식 스코어 시스템 빌리존과 제휴 |
| GK Billiards [확인] | 3쿠션용. 즉시 리플레이, 클립 다운로드 |
| CueScore, BilliardManager [확인] | 이닝 입력, 에버리지 자동 갱신, 하이런·파울 기록 |

국내 시스템의 화면별 세부 기능은 확인하지 못했다 [미확인]. 아래 항목은 확인된 기능에 당구 기록의 표준 항목을 더한 것이다.

게임의 이점: 당구장은 카메라 영상에 의존하지만, 게임은 모든 샷의 입력과 물리 결과를 정확히 갖고 있다.

## 3. 경기 중 스코어보드

### 3.1 표시 항목
- 선수 이름, 수지, 공 색
- 현재 점수 / 목표 점수
- 이닝 수
- 현재 이닝 연속 득점 (런)
- 에버리지 (득점 ÷ 이닝)
- 하이런 (최다 연속 득점)
- 샷 제한 시간, 남은 타임아웃
- 현재 차례 표시

### 3.2 동작
- 득점·파울·이닝 전환은 규칙 모듈이 자동 판정해 반영한다. 버튼 입력이 필요 없다.
- 실제 점수판과 비슷한 큰 숫자 중심의 구성. 접어서 최소화 가능.
- 로컬 대전에서는 판정 정정(되돌리기) 기능을 양쪽 동의로 허용.

## 4. 다시 돌려보기

### 4.1 원리
영상을 녹화하지 않는다. **초기 배치 + 샷 입력 목록**을 저장하고 물리 코어로 다시 계산한다.

- 한 경기 전체가 수 KB.
- 화질 손실이 없고 어떤 시점·배속으로도 볼 수 있다.
- 물리 코어 버전이 바뀌면 결과가 달라질 수 있으므로, 리플레이에 **코어 버전과 테이블 프로파일을 함께 저장**하고 구버전 코어를 보존한다.

### 4.2 즉시 리플레이 (경기 중)
- 방금 친 샷을 버튼 하나로 재생.
- 배속: 0.1× ~ 2×, 구간 반복.
- 온라인 대전에서는 자기 차례 시간을 쓰지 않는 범위에서 허용.

### 4.3 경기 리플레이 (경기 후)
- 이닝·샷 단위 목록에서 원하는 샷으로 이동.
- 득점한 샷만, 실패한 샷만 필터.
- 전체 자동 재생.

### 4.4 분석 오버레이
현실의 영상 리플레이에는 없는 기능.

| 오버레이 | 내용 |
|---|---|
| 궤적선 | 모든 공의 경로. 미끄럼·구름 구간 색 구분 |
| 샷 정보 | 당점 위치, 임팩트 속도, 고각, 스트로크 가속도·흔들림 |
| 회전 | 시점별 회전축과 회전량 |
| 충돌 정보 | 각 충돌의 두께, 입사각·반사각, 속도 변화 |
| 쿠션 포인트 | 각 쿠션 접촉 지점의 다이아몬드 수치 |
| 속도 그래프 | 시간에 따른 속도·회전 변화 |

### 4.5 다시 쳐보기
- 리플레이의 어느 샷에서든 "이 배치에서 다시 쳐보기"로 연습 모드 진입.
- 원래 샷의 입력값을 불러와 조금씩 바꿔가며 실험할 수 있다("당점을 반 팁 올렸다면?").
- 실패한 샷에 대해 AI의 추천 샷 보기 (PRD 05 훈수 모드).

### 4.6 클립과 공유
- 샷 또는 구간을 클립으로 저장.
- 공유는 링크 방식: 받는 사람의 브라우저에서 그대로 재생(영상 파일 아님).
- 영상 파일(WebM/MP4) 내보내기는 브라우저 녹화로 지원 [2차].
- 하이런, 최고 난도 샷 자동 하이라이트 [2차].

## 5. 경기 기록지

- 경기 종료 시 자동 생성.
- 이닝별 득점표 (공식 대회 기록지 형식: 이닝 번호, 각 선수의 이닝 득점, 누계).
- 요약: 최종 점수, 총 이닝, 에버리지, 하이런, 파울 수, 경기 시간, 평균 샷 시간.
- 이미지·링크로 공유.

## 6. 개인 대시보드

### 6.1 기본 통계 (1차)

| 항목 | 설명 |
|---|---|
| 에버리지 | 통산, 최근 10·30경기, 종목별 |
| 하이런 | 통산 최고, 최근 최고 |
| 승률 | 전체, 대인, 대AI(단계별) |
| 경기 수, 총 이닝, 총 득점 | 누적 |
| 득점 성공률 | 득점한 샷 ÷ 전체 샷 |
| 이닝당 득점 분포 | 0점, 1점, 2점… 이닝의 비율 |
| 에버리지 추이 | 일·주·월 그래프 |
| 추정 수지 | 기록 기반 수지와 다음 단계까지의 진행도 |
| 상대 전적 | 플레이어별, AI 단계별 |

### 6.2 샷 분석 (2차)

| 항목 | 설명 |
|---|---|
| 샷 유형별 성공률 | 뒤돌리기, 앞돌리기, 옆돌리기, 빗겨치기, 더블쿠션, 대회전 등 |
| 사용 분포 | 두께, 당점(히트맵), 속도, 고각 |
| 스트로크 품질 | 흔들림 평균, 속도 일관성 추이 |
| 실패 원인 | 두께 과다·부족, 속도 과다·부족, 회전 과다·부족 |
| 약점 배치 | 성공률이 낮은 배치 유형과 해당 연습 과제 연결 |

- 샷 유형 자동 분류와 실패 원인 추정은 구현 난도가 높다. 분류는 수구의 목적구·쿠션 접촉 순서와 방향으로 규칙 기반으로 시작한다.
- 실패 원인은 "실제 입력 주변에서 성공하는 입력"을 물리 코어로 찾아 차이를 계산하는 방식으로 추정한다.

### 6.3 화면 구성
- 상단: 핵심 수치 카드 (에버리지, 하이런, 승률, 수지)
- 중단: 추이 그래프
- 하단: 최근 경기 목록 → 기록지와 리플레이로 이동
- 별도 탭: 샷 분석, 상대 전적, 저장한 클립

## 7. 관전과 랭킹

- 진행 중인 공개 경기 목록, 링크로 관전 (PRD 06).
- 관전 화면에 양 선수의 실시간 스코어보드와 즉시 리플레이.
- 랭킹: 종목별 에버리지, 하이런, 수지 구간별 순위.

## 8. 데이터

| 데이터 | 저장 위치 |
|---|---|
| 경기 리플레이 (초기 배치, 샷 입력, 코어 버전, 프로파일) | 비로그인: 브라우저 / 로그인: 서버 |
| 경기 요약 (기록지 수치) | 위와 동일 |
| 샷 단위 통계 (유형, 성공 여부, 입력값) | 리플레이에서 재계산 가능, 조회용으로 별도 저장 |
| 클립 | 리플레이의 구간 참조 |

- 비로그인 기록은 로그인 시 서버로 이전.
- 데이터 내보내기(JSON, CSV) 제공.

## 9. 요구사항 요약

- [ ] 경기 중 점수·이닝·런·에버리지·하이런이 자동 갱신될 것
- [ ] 방금 친 샷을 한 번의 조작으로 다시 볼 수 있을 것
- [ ] 리플레이가 입력 기반으로 저장되고 코어 버전을 포함할 것
- [ ] 리플레이에서 궤적·샷 정보 오버레이를 켤 수 있을 것
- [ ] 리플레이의 임의 샷에서 연습 모드로 진입할 수 있을 것
- [ ] 경기 종료 시 이닝별 기록지가 생성될 것
- [ ] 대시보드에서 에버리지 추이와 최근 경기를 볼 수 있을 것

## 10. 미결 사항

- 국내 스코어보드의 화면 구성 추가 조사 (큐스코, 빌리보드 실물 확인)
- 샷 유형 분류 기준 (동호인 용어 정리 필요)
- 서버 보관 기간과 용량 정책
